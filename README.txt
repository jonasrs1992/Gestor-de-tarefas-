GITHUB PAGES - INSTRUÇÕES
1. Crie um repositório público no GitHub.
2. Envie os arquivos index.html, manifest.webmanifest, sw.js, icon-192.png e icon-512.png para a raiz.
3. Em Settings > Pages, escolha Deploy from a branch, main, /(root), Save.
4. Abra o endereço informado pelo GitHub Pages e instale pelo menu do Chrome.
Os dados ficam apenas no navegador/dispositivo, não são compartilhados automaticamente.
